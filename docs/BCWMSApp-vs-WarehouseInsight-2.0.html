Boşluk (Yok+Kısmi)

Yorum: Çekirdek depo iş akışları (Mal Kabul, Put-Away, Toplama, Sevkiyat, Sayım, Üretim, Montaj, License Plate) BCWMSApp'te aksiyon-yetenekli ve postlayabilir durumda — bu modüllerde parite güçlü. Ana boşluklar iki başlıkta yoğunlaşıyor: (1) Sorgu/görünürlük (item resmi, son hareketler, Whse. Entries, Lot/Seri seçici, item/bin etiketi) ve (2) Verimlilik/konfor katmanı (Totes'a toplama, Card/Grid görünüm, Hide/Show tamamlananlar, Scratchpad offline, satıcı barkodu eşleme, oto lot/seri, Quantity Extensions, Auto-post/Auto-split, Wave picking, konfigüre edilebilir menü). Buna karşılık bizde Warehouse Insight'ta hiç olmayan güçlü özellikler var (bkz. son bölüm).

3. Ek — Bizim Artılarımız (Warehouse Insight'ta yok / zayıf)

Karşılaştırmanın diğer yönü: BCWMSApp'te olup Warehouse Insight 2.0'da bulunmayan güçlü yetenekler.

  • Kalite Yönetimi — Quality Order (pass / fail / karantina bin, ANSI'ye göre otomatik örnek boyutu) + Microsoft Quality Management entegrasyonu + Toplama/Mal Kabul/Sevkiyat'ta QC-block guard (bloklu lot/seri sevk/pick engellenir). Warehouse Insight'ta kalite modülü yoktur.
  • License Plate Nesting (parent/child) + SSCC-18 üretimi (GS1 kontrol hanesiyle). Warehouse Insight LP'si düz yapıdadır.
  • Modern kimlik doğrulama — Azure AD OAuth (device-code / token) + yerel kullanıcı (tuz+hash) + cihaz parmak izi/kaydı. (WHI: NAV web-service kimlik bilgileri.)
  • Bulut yazdırma — PrintNode + self-hosted ZPL kanalı + yazıcı token yönetimi. (WHI: NAV service-tier yazıcısı.)
  • Rol tabanlı dinamik belge filtresi — kullanıcı rollerine göre %USER%/%LOC%/%TODAY% token'larıyla otomatik filtreleme.
  • Kamera (ML Kit) + GS1-128 AI yerleşik tarama ve Scan & Verify yanlış-toplama önleme.
  • Native Business Central SaaS — bulut, OData v2 API sayfaları üzerinde çalışır (WHI'nin NAV/service-tier modeline karşı konumlanma avantajı).
  • Push bildirim relay (Firebase) altyapısı.
