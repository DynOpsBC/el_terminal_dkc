# BCWMSApp

BCWMSApp is an advanced warehouse execution extension for Microsoft Dynamics 365 Business Central SaaS. It adds license plate control, mobile scanning workflows, operational dashboards, and warehouse movement telemetry without requiring a separate warehouse management platform.

The solution supports receiving, put-away, picking, shipping, movement, counting, production consumption, production output, assembly, barcode parsing, device registration, and warehouse manager review flows. Mobile workers use the Android companion app for scan-first execution, while planners and supervisors use embedded Business Central pages and React control add-ins.

BCWMSApp is built for multi-tenant SaaS deployments with role-based permission sets, per-tenant configuration, Application Insights telemetry, and an Azure Function push relay for device notifications.
