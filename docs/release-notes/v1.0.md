# BCWMSApp v1.0 Release Notes

BCWMSApp v1.0 is the first AppSource release candidate for DynOps advanced warehouse execution on Microsoft Dynamics 365 Business Central SaaS.

## Sprint Summary

- Sprint 0 established the AL, Android, web, and push-relay foundations.
- Sprint 1 delivered core setup, authentication, device registration, and shared Android architecture.
- Sprint 2 added item, bin, barcode, and inquiry foundations.
- Sprint 3 delivered license plate headers, lines, SSCC generation, labels, movement ledger, and LP APIs.
- Sprint 4 delivered receiving, put-away, and directed warehouse execution workflows.
- Sprint 5 delivered pick, short-pick, shipment, and packing workflows.
- Sprint 6 delivered movement, production consumption, production output, and assembly flows.
- Sprint 7 delivered embedded SPAs, pick board, LP browser, push relay, and telemetry plumbing.
- Sprint 8 delivered count sheets, variance review, role center cues, WI migration scaffolding, upgrade handling, and i18n refinements.
- Sprint H delivered hardening, AppSource RC assets, CI workflows, contract tests, KQL dashboards, runbooks, security audit, and v1.0 version bumps.

## Functional Coverage

The release covers the warehouse modules Receive, Putaway, Pick, Ship, Move, Count, Consume, Output, plus Assembly and License Plate control. License plate workflows include build, nest, movement ledger, labels, factboxes, and shipment/production integration.

## Integration Surface

BCWMSApp exposes 50+ custom API endpoints across license plates, receipts, putaways, picks, shipments, movements, count sheets, production consumption, production output, assemblies, items, bins, devices, and barcodes. A Newman contract suite covers 14 resource groups and 70 smoke requests.

## User Experiences

Business Central pages provide setup, queues, cards, role center cues, count variance review, and warehouse manager workflows. Two embedded SPAs support supervisor execution views. Android mobile supports secure authentication, scan-first warehouse execution, offline cache, sync, and device registration.

## Quality and Operations

The AL test suite includes 25+ test codeunits with 100+ assertions across core warehouse flows. CI now includes AL audit hooks, nightly contract tests, security scanning, and release automation. Application Insights KQL dashboards cover API latency, LP throughput, scan funnel drop-off, and device heartbeat. Operations documentation includes on-call runbooks, troubleshooting, OpenAPI, security audit, and AppSource submission checklist.

## Architecture

The architecture is multi-tenant SaaS-ready with AL permission separation, tenant-scoped device registration, Azure Function push relay, HMAC webhook verification, Application Insights telemetry, Android Keystore token protection, SQLCipher local storage, and Entra authentication.

## Remaining External Actions

Before AppSource submission, final logo, screenshots, public documentation URL, privacy URL, license URL, support validation, production telemetry connection, AppSourceCop report, Play Store closed testing evidence, and signed release artifacts must be attached by the release orchestrator.
